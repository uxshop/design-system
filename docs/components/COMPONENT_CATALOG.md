## Component Organization

Components are organized by category for easy discovery:

- **Feedback & Messaging** — User notifications and status messages
- **Layout & Containers** — Structural components for organizing content
- **Navigation** — Help users move through your app
- **Form Inputs & Controls** — Interactive form elements
- **Form Helpers** — Labels, hints, validation messages
- **Data Display** — Show data in various formats
- **Overlay & Dialogs** — Modal and overlay components
- **Utilities & Other** — Miscellaneous utility components

## How to Use This Catalog

1. **Browse by category** — Find the component category that matches your need
2. **Click the component link** — Read the full documentation with examples
3. **Check props table** — See what configuration options are available
4. **Review examples** — Copy and adapt code snippets for your use case
5. **Check A11y notes** — Ensure you're using the component accessibly

Each component documentation includes:
- **Purpose** — What the component does
- **Props** — Configuration options with types
- **Slots** — Customizable content areas
- **Events** — What the component emits
- **Usage Examples** — Real-world Vue 3 examples
- **Styling** — CSS customization options
- **A11y Notes** — Accessibility considerations
- **Related Components** — Similar or complementary components
