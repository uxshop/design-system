# SkeletonTable Component

## Purpose
Table skeleton loader for tabular data.

## Status
✅ Stable — Safe for new projects

## Import
```ts
import { SkeletonTable } from '@tray-tecnologia/design-system';
```

## Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| rows | number | 5 | Number of rows |
| columns | number | 3 | Number of columns |
| height | number \| string | '2rem' | Row height |

## Styling
- `.ui-skeleton-table` — Table container
- `.ui-skeleton-table-cell` — Table cell

## Related Components
- [Skeleton](./skeleton.md) — Single skeleton
- [IndexTable](./index-table.md) — Actual table

## Deprecations
None. This component is stable.
