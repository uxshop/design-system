# SkeletonList Component

## Purpose
List skeleton loader for multiple items.

## Status
✅ Stable — Safe for new projects

## Import
```ts
import { SkeletonList } from '@tray-tecnologia/design-system';
```

## Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| count | number | 5 | Number of items |
| height | number \| string | '2rem' | Item height |

## Styling
- `.ui-skeleton-list` — List container
- `.ui-skeleton-list-item` — List item
